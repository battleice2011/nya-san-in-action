# 魔法少女にゃーさん in Action

ブラウザで遊べるWeb公開版です。

## GitHub Pagesへの公開
1. GitHubでPublicリポジトリを作成
2. このフォルダの中身をリポジトリのルートへアップロード
3. Settings → Pages → Build and deployment → Source: Deploy from a branch
4. Branch: `main` / Folder: `/ (root)` を選んでSave
5. 数分待つとGitHub PagesのURLでプレイできます

`index.html` はリポジトリのルートに置いてください。

## 操作
- ← / → または A / D：移動
- ↑ / W / Space：ジャンプ
- Z / X：攻撃
- スマートフォン：画面下のタッチボタン
